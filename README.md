# University Store

Static storefront for official university merchandise — product catalog, cart, checkout and blog pages.

**Live:** https://urolovforever.github.io/store/

Built as a front-end practice project: plain HTML, CSS and JavaScript, no frameworks and no build step. Every push to `main` is deployed to GitHub Pages automatically by a GitHub Actions workflow (`.github/workflows/static.yml`).

## Pages

Catalog (`shop.html`), product page, cart, checkout with confirmation, gallery, blog, FAQ, about and contact pages, plus a custom 404.

## Running locally

No dependencies — clone and open `index.html` in a browser, or serve the folder:

```bash
git clone https://github.com/urolovforever/store.git
cd store
python3 -m http.server 8000   # http://localhost:8000
```
